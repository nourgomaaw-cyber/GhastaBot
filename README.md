# GUDELINO

موقع شات خاص بفريقك، بتصميم داكن بنفسجي مستوحى من تطبيقات المجتمعات، ويشمل:
- إنشاء حساب وتسجيل دخول بالبريد وكلمة المرور.
- قنوات عامة ينشئها المستخدم.
- محادثات خاصة بالبريد الإلكتروني.
- رسائل مباشرة وتحديث لحظي.
- رفع ملفات متعددة مع شريط تقدم ومحاولات إعادة تلقائية للرفع الكبير (TUS).
- تنزيل الملفات من روابط مؤقتة خاصة.

## مهم قبل التشغيل
المشروع يحتاج مشروع Supabase. الموقع نفسه لا يستضيف الملفات؛ Supabase Storage هو مكان التخزين. حد 5GB الموجود في SQL هو حد إعداد مبدئي، وقد تحتاج تغييره حسب خطة التخزين المتاحة وحجم الملفات المسموح في مشروعك. لا يوجد تخزين غير محدود مجانًا.

## 1) إنشاء قاعدة البيانات والتخزين
1. افتح https://supabase.com وأنشئ مشروعًا جديدًا.
2. من لوحة المشروع افتح SQL Editor.
3. افتح الملف `supabase/schema.sql` وانسخ محتواه بالكامل إلى SQL Editor ثم اضغط Run.
4. من Authentication > Providers تأكد أن Email مفعّل.
5. للاختبار السريع، من Authentication > Settings يمكنك تعطيل تأكيد البريد الإلكتروني. في الاستخدام الفعلي اترك التأكيد مفعّلًا.
6. من Project Settings > API انسخ Project URL و anon/public key. لا تستخدم service_role key في المتصفح أبدًا.

## 2) تشغيله على أندرويد باستخدام Termux
ثبّت Termux من مصدر موثوق، ثم نفّذ:

```bash
pkg update -y && pkg upgrade -y
pkg install nodejs-lts git -y
termux-setup-storage
cd ~/storage/downloads
unzip gudelino.zip
cd gudelino
npm install
cp .env.example .env
nano .env
```

ضع بيانات Supabase في `.env` هكذا:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY
```

احفظ في nano باستخدام `CTRL+O` ثم Enter ثم `CTRL+X`. على الهاتف قد تحتاج زر CTRL في لوحة Termux.

ثم شغّل:

```bash
npm run dev -- --host 0.0.0.0
```

افتح المتصفح على:
`http://127.0.0.1:5173`

لإيقاف الخادم اضغط `CTRL+C`.

## 3) بناء نسخة إنتاج
```bash
npm run build
```
ينتج الموقع داخل مجلد `dist`. ارفع محتويات `dist` إلى استضافة مواقع ثابتة مثل Cloudflare Pages أو Netlify أو Vercel، وأضف متغيري البيئة نفسهما في إعدادات الاستضافة ثم أعد البناء.

## 4) تجربة الموقع
1. افتح الموقع وأنشئ حسابًا بالبريد وكلمة مرور.
2. بعد الدخول ستظهر قناة افتراضية باسم "عام".
3. اضغط + بجانب قنوات المحادثة لإنشاء قناة.
4. اضغط "محادثة خاصة" واكتب بريد حساب العضو الآخر.
5. اضغط علامة + بجانب مربع الرسالة لإرفاق ملفات.

## الأمان والحدود
- لا تضع مفتاح `service_role` في `.env` الخاص بالواجهة أو في أي كود يراه المستخدم.
- الملفات داخل bucket خاص، والتنزيل عبر رابط مؤقت.
- لا تفتح سياسات Storage للعامة.
- حد 5GB في SQL ليس وعدًا بأن الخطة المجانية ستسمح بهذا الحجم؛ حدود Supabase الفعلية تعتمد على الخطة والإعدادات. راجع حدود التخزين والرفع في لوحة Supabase قبل مشاركة الموقع.
- الرفع الكبير يستخدم بروتوكول TUS. استكمال الرفع يعتمد على صلاحية جلسة المستخدم واتصال الشبكة.
- هذا إصدار أولي قابل للتطوير، وليس بديلًا عن مراجعة أمنية قبل استخدامه لمجموعة كبيرة أو ملفات حساسة.
- حاليًا إنشاء القنوات متاح لأي مستخدم مسجل، وأي مستخدم يستطيع بدء محادثة خاصة مع حساب يعرف بريده. أضف نظام دعوات/رتب ومراجعة صلاحيات قبل فتح التسجيل للعامة.
